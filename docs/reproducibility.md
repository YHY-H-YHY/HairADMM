# 复现实验与公平比较规范

本文档将三个容易混淆的问题分开：

1. HairADMM 是否保持了与历史基线相同的发型目标？
2. 哪一个碰撞处理组件真正减少了线段穿模？
3. 在统一计时口径下，专门化实现究竟快多少？
4. Active 时序门禁是否减少了帧间抖动而没有过度平滑正常运动？

## 1. 所有方法必须共享的问题数据

公平比较时，所有方法必须读取同一份逐帧标准数据包，并接收完全相同的：

- Init 和源对齐发型；
- 发丝拓扑、有效点掩码和固定发根；
- 目标人体网格；
- Guide 集合；
- Guide 与 Normal 的 KNN 索引和权重；
- 源拉普拉斯或源偏移目标；
- 逐点局部权重；
- fidelity、KNN 和方向保持能量权重。

数据包由 hairs_adaption/qp_objective_bundle.py 验证。任何比较方法都不能在自己的
路径中重新生成 KNN、权重、Guide 集合或人体几何，否则比较的将不再是同一个问题。

## 2. 针对新算法主张的实验

新实验必须把 x-update、z-update 和自适应 $C$ 的贡献分开。最小诊断实验包括：

1. **历史 CVXPY/OSQP。** 使用共享基础目标和历史顶点半空间约束，通过通用 QP
   接口求解。
2. **使用 QP 式顶点约束的结构化 ADMM。** 使用自定义的坐标共享图结构 x-update，
   但保留历史顶点切平面碰撞语义。这是隔离速度来源的主要基线。
3. **几何感知的顶点 ADMM。** 把标量平面投影替换成人体外部 SDF z-update，但
   $C$ 只包含顶点。
4. **感知线段的 ADMM。** 加入确定性的线段内部采样行，最大间距为 2 mm。
5. **完整 HairADMM。** 在 outer 求解后，再加入 Embree 检出的交点邻域行。
6. **完整 HairADMM + 时序门禁。** 在连续三帧有效时，只对超过 Init 运动阈值的
   二阶位移尖峰加入 ADMM 球约束。

这些比较分别回答：

- 1 对 2：在共享目标值相近时，图结构 x-update 是否降低了通用建模和重复求解成本？
- 2 对 3：几何 z 近端算子带来了什么变化？
- 3 对 4：线段内部行消除了多少端点无法观察到的穿模？
- 4 对 5：在均匀采样之外，精确残余交点反馈还有多少贡献？
- 5 对 6：时序门禁减少了多少抖动，其形状保持和真实运动代价是多少？

单帧公开入口只暴露几何 one-step 配置；完整序列实验额外启用时序门禁。在论文最终数字
发布前，六组实验都必须保存：

- 完整配置；
- 各阶段日志；
- 输出几何；
- 独立评估器生成的 JSON。

不能只根据最终输出倒推出中间消融结果。

## 3. 评价指标

所有方法必须使用同一个独立评估器：

- **点穿透：** 使用 winding-number 有符号距离，统计位于人体内部的有效非发根点；
- **线段相交：** 使用 Embree 精确统计线段—三角形交点，排除发根相邻线段；
- **形状保持：** 在同一批有效行上计算共享的 fidelity、KNN 和方向项；求解器罚项及
  增广拉格朗日项不是可横向比较的目标；
- **时间：** 分别报告系统构造、Guide 求解、Normal 目标构造、Normal 求解、碰撞查询
  和算法总时间。
- **时序：** 只在连续三帧都有效的非发根点上统计离散二阶位移；同时报告均值、
  95 分位数和尖峰点比例，并排除 padding。

padding 和发根必须在所有方法中一致排除。评价代码不能把求解器自己的局部内外判断
直接当作 ground truth。

## 4. 计时规则

受控速度比较必须满足：

- 使用同一台机器和相同线程限制；
- 使用同一批帧和同一批标准数据包；
- 使用相同的 cold start 或 warm start 策略；
- 对 I/O 与几何预处理采用相同的包含或排除规则；
- 分开记录 setup、factorization、iteration 和 collision query 时间；
- 先执行一次不计入结果的预热，再重复多次。

当前仓库记录的历史 QP 时间约为 300 s/帧，HairADMM 为 4.119 s/帧。二者来源不同：

- QP 是历史 wall-clock 工程估计，并由输出文件时间戳进行部分交叉检查；
- 4.119 s 是求解器记录的算法内部均值，不包含无关 I/O 和离线评估。

它们能够说明“分钟级与秒级”的工程差异，但不能证明一个精确、完全公平的加速倍数。

## 5. 当前保留结果的状态

当前数字是**初步历史证据**。它们表明，保留的 HairADMM 输出比保留的历史 QP 输出
具有更少的测量点穿透和线段相交，并且在已记录机器上达到秒级算法时间；代码同时实现
了 active 时序门禁。最终报告仍需在统一数据上分别隔离快速求解、线段约束和时序门禁。

在受控实验完成前，不应声称：

- ADMM 首次被用于发丝优化；
- OSQP 不是 ADMM 方法；
- 有限采样能够严格保证连续线段无相交；
- 历史 QP 时间和当前 HairADMM 时间构成完全同口径的精确加速倍数。
